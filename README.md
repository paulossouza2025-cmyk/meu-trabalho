# MEU TRABALHO

Aplicativo pessoal mobile-first/PWA para organizar a jornada.

## Incluído
- Hoje: trabalho/folga e próximo trabalho
- Minha Escala: setembro/2026, período atualmente cadastrado
- Painel Operacional: links para Embraport e Santos Pilots
- Registrar Turno
- Histórico local no aparelho
- PWA com service worker para funcionamento offline após o primeiro acesso

## Privacidade
Os registros de turno ficam no `localStorage` do navegador/aparelho. Não há banco de dados nem senha armazenada pelo aplicativo.

## Publicação
Este projeto pode ser publicado gratuitamente em GitHub Pages.
